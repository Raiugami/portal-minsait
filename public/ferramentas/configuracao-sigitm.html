Configuração SIGITM

Roteiro para preparar o computador de um novo analista SIGITM, em três trilhas.

A execução é feita por um assistente local no seu Windows. O pacote de instalação contém configurações internas e não é publicado aqui: peça-o à equipe pelo canal interno (SharePoint ou Teams).

Trilha SIGITM TI · 2

  1. Instalar as ferramentas automatizadas
  2. Preparar o comando zip exigido pelo SDKMAN
  3. Instalar SDKMAN e as versões do SIGITM 2
  4. Instalar Maven 3.2.5 local para o módulo de inventário
  5. Aplicar a configuração local segura
  6. Disponibilizar acesso ao Nexus pelo processo aprovado
  7. Definir a identidade Git do usuário
  8. Clonar os repositórios SIGITM TI · 2
  9. Selecionar versões automaticamente nos projetos
  10. Preparar o estilo da IntelliJ e importar os módulos Maven
  11. Preparar o build dos módulos locais (build de domínio apenas quando necessário)
  12. Vincular o projeto Gradle e revisar o workspace na IDE
  13. Validar a inicialização local (opcional)

Trilha SIGITM TA · 3

  1. Instalar as ferramentas automatizadas
  2. Preparar o comando zip exigido pelo SDKMAN
  3. Instalar SDKMAN e as versões do SIGITM 3
  4. Aplicar a configuração local segura
  5. Disponibilizar acesso ao Nexus pelo processo aprovado
  6. Definir a identidade Git do usuário
  7. Clonar os repositórios SIGITM TA · 3
  8. Selecionar versões automaticamente nos projetos
  9. Preparar o estilo da IntelliJ nos projetos
  10. Configurar Oracle e os aliases TNS
  11. Validar os apontamentos internos com a equipe
  12. Construir os módulos locais necessários (domínio apenas quando houver mudanças de tabelas/campos)
  13. Gerar o workspace Maven, configurar a importação e vincular o servidor como Gradle
  14. Preparar os perfis de execução do Server e do Client
  15. Confiar e revisar o workspace na IDE
  16. Subir e validar o ambiente local (opcional)

Trilha PL/SQL Developer

  1. Instalar Oracle Instant Client 19c
  2. Configurar TNS_ADMIN e NLS_LANG
  3. Instalar o PL/SQL Developer aprovado pela empresa
  4. Vincular o Oracle Home e a OCI na IDE
  5. Importar as conexões corporativas aprovadas
  6. Aplicar as preferências de segurança SQL
